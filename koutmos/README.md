# Elixir For Finance Livebook Guides

## Introduction

The Livebook files bundled with the Elixir For Finance book are meant to help you learn and experiment with some of the material covered in the text. In addition, they can also act as useful references
if you ever need to remind yourself how to do something.

## Getting started

Using Livebook is super easy. All you need to do is run a few CLI commands, and you'll be up and
running in no time.

1. Start off by setting up Hex and Rebar: `mix local.rebar --force && mix local.hex --force`
2. Then install Livebook so that it is globally accessible: `mix escript.install hex livebook`
3. Run the Livebook script to start up Livebook with the correct env vars and to automatically
   open up the index document: `./start_livebook.sh`
4. Using the Livebook document index, open up any of the accompanying files and start
   experimenting!
